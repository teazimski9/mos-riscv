## Mathematical Operating System
MOS is OS built around mathematics.

This OS is not made to be used as a normal, usable OS. It's a testing OS designed only for mathematical and other scientific experiments. (For RISC-V architecture!)

It is not required or intended for everyday use by users. Its main purpose is to test mathematical functions, algorithms, and other scientific concepts.

**Caution:** This OS is still experimental and may be unstable, incomplete, or broken. Features might not work as expected, and bugs or errors are possible. Use it for testing and experimentation only.
